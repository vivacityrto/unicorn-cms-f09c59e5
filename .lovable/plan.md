# Phase 1 — `dd_obligation_audience` & `dd_obligation_recurrence`

Single migration. No code changes, no edge function, no frontend. Phase 1 only.

## Migration SQL

```sql
-- 1. dd_obligation_audience
CREATE TABLE public.dd_obligation_audience (
  id          integer GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  value       text       NOT NULL UNIQUE,
  label       text       NOT NULL,
  sort_order  integer    NOT NULL DEFAULT 0,
  is_active   boolean    NOT NULL DEFAULT true,
  created_at  timestamptz NOT NULL DEFAULT now()
);

GRANT SELECT ON public.dd_obligation_audience TO authenticated;
GRANT ALL    ON public.dd_obligation_audience TO service_role;

ALTER TABLE public.dd_obligation_audience ENABLE ROW LEVEL SECURITY;

CREATE POLICY dd_obligation_audience_read
  ON public.dd_obligation_audience
  FOR SELECT
  USING (true);

CREATE POLICY dd_obligation_audience_admin
  ON public.dd_obligation_audience
  FOR ALL
  USING (public.is_vivacity())
  WITH CHECK (public.is_vivacity());

-- 2. dd_obligation_recurrence (identical structure)
CREATE TABLE public.dd_obligation_recurrence (
  id          integer GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  value       text       NOT NULL UNIQUE,
  label       text       NOT NULL,
  sort_order  integer    NOT NULL DEFAULT 0,
  is_active   boolean    NOT NULL DEFAULT true,
  created_at  timestamptz NOT NULL DEFAULT now()
);

GRANT SELECT ON public.dd_obligation_recurrence TO authenticated;
GRANT ALL    ON public.dd_obligation_recurrence TO service_role;

ALTER TABLE public.dd_obligation_recurrence ENABLE ROW LEVEL SECURITY;

CREATE POLICY dd_obligation_recurrence_read
  ON public.dd_obligation_recurrence
  FOR SELECT
  USING (true);

CREATE POLICY dd_obligation_recurrence_admin
  ON public.dd_obligation_recurrence
  FOR ALL
  USING (public.is_vivacity())
  WITH CHECK (public.is_vivacity());

-- 3. Seed audience
INSERT INTO public.dd_obligation_audience (value, label, sort_order) VALUES
  ('rto',           'RTO',           10),
  ('cricos',        'CRICOS',        20),
  ('rto_or_cricos', 'RTO or CRICOS', 30)
ON CONFLICT (value) DO NOTHING;

-- 4. Seed recurrence
INSERT INTO public.dd_obligation_recurrence (value, label, sort_order) VALUES
  ('annual_fixed',       'Annual — fixed date', 10),
  ('annual_window',      'Annual — window',     20),
  ('rolling_per_tenant', 'Rolling per tenant',  30),
  ('always_open',        'Always open',         40)
ON CONFLICT (value) DO NOTHING;
```

## Pattern verification

- `is_vivacity()` exists in `public` schema ✅
- Column shape matches existing `dd_org_type` (id identity, value, label, sort_order, is_active, created_at) ✅
- Policy pattern: public read + vivacity-only write — mirrors the project's lookup convention ✅
- No functions created in this phase → Phase 0 `SET search_path = ''` rule is N/A here; all references in policies are already fully qualified (`public.is_vivacity()`)
- No FK references added to `compliance_obligations` yet — that's Phase 2

## Verification (post-migration)

```sql
SELECT count(*) FROM public.dd_obligation_audience;   -- expect 3
SELECT count(*) FROM public.dd_obligation_recurrence; -- expect 4

-- Confirm every existing value in compliance_obligations is covered
SELECT DISTINCT c.audience
  FROM public.compliance_obligations c
  LEFT JOIN public.dd_obligation_audience a ON a.value = c.audience
 WHERE a.id IS NULL;   -- expect 0 rows

SELECT DISTINCT c.recurrence
  FROM public.compliance_obligations c
  LEFT JOIN public.dd_obligation_recurrence r ON r.value = c.recurrence
 WHERE r.id IS NULL;   -- expect 0 rows
```

Pre-audit (already run): existing audience values = `rto`, `cricos`; existing recurrence values = `always_open`, `rolling_per_tenant`, `annual_fixed`. All covered.

## Rollback

```sql
DROP TABLE IF EXISTS public.dd_obligation_audience;
DROP TABLE IF EXISTS public.dd_obligation_recurrence;
```

Safe — no FKs reference these tables yet.

## Risk

Negligible. Two new isolated lookup tables, no consumers, no FK wiring, no impact on existing queries, views, or RLS policies. `is_vivacity()` is the same gate used by existing `dd_*` admin policies.
